# Sistema de Reserva de Laboratórios

Sistema web desenvolvido como Trabalho de Conclusão de Curso em Engenharia da Computação.

## Objetivo

Centralizar o gerenciamento e a reserva de laboratórios acadêmicos, reduzindo conflitos de utilização e mantendo um histórico das solicitações.

## Perfis de usuário

- Aluno
- Professor
- Administrador

## Tecnologias planejadas

- React.js
- Django
- Django REST Framework
- PostgreSQL
